# Fusion Studios

A polished, responsive one-page website for Fusion Studios in Marol, Mumbai. The experience presents the studio’s hair, skin, nail and tattoo services and routes appointment requests to WhatsApp.

## Application and user workflow

The application is a mobile-first service discovery and appointment-request website. Visitors can understand the studio’s offering without creating an account or navigating multiple pages.

1. **Discover:** The hero introduces Fusion Studios and highlights its four beauty disciplines.
2. **Explore:** Visitors review curated services, durations and starting prices.
3. **Understand:** The standards and process sections explain how the studio approaches consultation, hygiene and aftercare.
4. **Choose:** Selecting a package opens the booking form with that service already selected.
5. **Request:** The visitor enters their name, phone number, preferred date and time.
6. **Confirm:** A formatted appointment request opens in WhatsApp, where the studio confirms availability directly.
